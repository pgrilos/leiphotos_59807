## Overview

This is an Eclipse project containing the code and supporting materials provided for Practical Assignment 1. The project is organized according to the design solution presented in the assignment specification.

The main goal of this assignment is to help students practise the object-oriented programming and design techniques taught in the course.

The project focuses on a photo management application.

This version includes a graphical user interface, available through `GUIClient`, which supports several features, including:

- Viewing the contents of the main photo library
- Viewing the contents of the trash
- Viewing the contents of predefined albums by double-clicking them
- Selecting one or more photos and adding them to an album
- Deleting photos
- Deleting albums

The project also includes a simpler client application, `SimpleClient`, which is used to test several additional features of the system.

## Requirements

- JDK 17 or later installed. Oracle JDK or OpenJDK is recommended.
- A Java IDE. Eclipse is recommended.
- The SonarLint plugin is recommended for code quality analysis.

With the recommended requirements installed, the project can be imported directly into Eclipse.

After completing the implementation of the missing classes, both `SimpleClient` and `GUIClient` should be ready to run.

Other development environments may require additional configuration or dependency management.

In case the SWT-dependent classes do not compile or run correctly, use `SimpleClient` instead of spending time solving GUI-related compatibility problems.
